--- QUESTIONS A / ANSWERS A ---
問題1. 野球を何として使いますか。本文から英語で答えなさい。2. 目標は何ですか。本文から英語で答えなさい。3. 何を通じて学びますか。本文から英語で答えなさい。4. プロジェクトにはどのような効果がありますか。本文から英語で2語答えなさい。5. 試合が難しいとき、何をしますか。本文から英語で答えなさい。
解答・解説1. as a tool根拠英文：We use baseball as a tool.根拠の意味：私たちは野球を道具として使います。なぜ：as a tool が野球の役割を表しています。2. peace根拠英文：Our goal is peace.根拠の意味：私たちの目標は平和です。なぜ：goal の内容が peace です。3. the project根拠英文：We learn through the project.根拠の意味：私たちはそのプロジェクトを通じて学びます。なぜ：through の後ろが the project です。4. positive effect根拠英文：The project has a positive effect.根拠の意味：そのプロジェクトにはよい効果があります。なぜ：positive effect が効果の内容です。5. help each other根拠英文：If the game is difficult, we help each other.根拠の意味：もし試合が難しければ、私たちは助け合います。なぜ：if節の後ろの行動が help each other です。
