# みかみ塾 数学問題バンク 作業基盤

このディレクトリは数学問題バンク構築の隔離作業領域。
main には混ぜず、数学専用リポジトリ作成後に移管する。

## 元データ
- 中学実力錬成データ.zip
- スタンダードデータ.zip
- winpassデータ.zip

## 固定処理順
1. ZIP全ファイル棚卸し
2. 中1・中2・中3へ分類
3. 大単元・小単元へ正規化
4. 問題と解答を対応付け
5. 問題を実際に再計算して正答監査
6. 不一致・欠落・番号ずれ・条件不足・図不足を抽出
7. 重複・同型問題をグループ化
8. 難易度・前提知識・つまずきタグを付与
9. 類題生成可能性を分類
10. 正本問題バンクへ反映

## 原則
- 元解答を無条件に正しいとみなさない
- 元問題文を勝手に修正せず、原文と修正版を分離保存する
- 出典・元番号を必ず残す
- 図表問題は図の参照関係を保持する
- 類題は正本化済み問題からのみ生成する
- 処理はバッチ単位でチェックポイントを保存し、途中停止後は未処理分から再開する
