# V11 山口県公立高校入試・英語読解モデル

作成目的: v11の中3長文を「一般的な長文」だけでなく、山口県公立高校入試の実際の読解量・設問処理に近づける。著作権保護のため過去問本文は転載せず、実問題画像と公開分析から形式・語数・処理要求のみを抽出する。

**このアプリは長文読解専用であり、自由英作文・条件英作文などの英作文は対象外とする。実際の入試に英作文が含まれていても、v11の山口県型100題には入れない。**

## 実問題を確認して固定する事実

### 2024年度（令和6年度）
- 公開されている実問題画像を確認。長文では、本文内容について理由・事実を4択で判定する問題、本文後の短い対話を本文内容に合わせて語句補充する問題がある。
- 進研ゼミの問題分析では、大問2 約100語、大問3 約230語、大問4 約170語、大問5 約350語。長文読解が50点中29点を占める。
- 文章だけでなくグラフ・資料を読み取る問題も含む。

### 2025年度（令和7年度）
- 実問題・解答公開ページおよび大問別解説を確認。
- 大問3は「対話文＋パンフレット等の資料」の統合読解。時刻・イベント条件・行動順序を合わせて判断する設問、資料内容一致の複数選択がある。
- 単純な本文抜き出しではなく、先に設問条件を把握し、本文・資料から必要情報を拾って統合する処理が必要。

### 2026年度（令和8年度）
- 公開されている実問題画像を確認。
- 長文読解で、参加理由・準備内容などを4択で判断する問題、本文内容に対し指定語数（例: 4語）で英語回答する問題、本文後の日記・要約文を内容に合わせて補充する問題がある。
- 進研ゼミ分析では約440語の長文が出題。長文読解は大問6問中4問。
- 実試験には別大問の英作文もあるが、本アプリでは扱わない。

## v11へ反映する中3読解設計

中3はすべてを140〜270語に固定しない。通常長文と入試級を混在させる。

- Standard: 140〜220語
- Medium-long: 230〜320語
- Yamaguchi-long: 350〜450語

50題の1バッチに中3が16題ある場合、原則として次の配分を目標とする。
- Standard 8題
- Medium-long 4題
- Yamaguchi-long 4題

長文化のための共通sentence bank・意味の薄い水増しは禁止。各話固有の出来事、判断、根拠、結果で語数を満たす。

## 中3 A/B問題へ入れる山口県型

A/B各5問の既存契約は維持しつつ、10問全体を抜き出し一辺倒にしない。各本文の難度に応じて次の形式を混ぜる。

1. 内容一致・不一致（4択相当）
2. 行動理由・発言理由の判断
3. 英問英答（本文内容を2〜6語程度で答える）
4. 要約・日記・会話への語句補充
5. 指示語・言い換え・文脈語句
6. 複数情報の順序・条件整理
7. 本文＋表・時刻表・パンフレット・簡易グラフの統合読解
8. 根拠英文を直接コピーするだけでは解けない推論型。ただし根拠英文・根拠訳・理由は必ず保持する。

Yamaguchi-long 4題のうち最低2題は資料統合型、最低2題は英問英答または要約補充型を含める。

## 英作文は対象外

自由英作文・条件英作文・20〜30語英作文は、この長文読解アプリには実装しない。`freeWrite`、`freeWriteTask`、英作文model answer、英作文採点条件は山口県型100題の要件に含めない。短い英問英答は、本文内容を読み取って2〜6語程度で答える**読解設問**としてのみ扱う。

## 山口県入試型100題

1000題全体の中に、山口県公立高校入試の長文読解に近いオリジナル100題を専用枠として保持する。100題はすべて読解問題とし、英作文は0題とする。内容一致、理由、推論、文挿入、要約補充、文脈語句、資料統合などを偏りなく配置する。

## chronologyとの優先順位

山口県入試級へ長文化しても、割当教科書・単元までの語彙/文法時系列を破らない。story-essentialな未習語は既存の `unlearned_local_required` で正式日本語glossを付ける。未習文法を入試らしさのために先取りすることは禁止。

## 品質gate

中3最終gateには以下を追加する。
- length tierが設計どおり分散している
- 350〜450語のYamaguchi-longが所定数ある
- 資料統合型・英問英答・要約補充が所定数ある
- 10問すべてが同一設問型になっていない
- 本文と資料に必要な全情報が存在する
- 解答根拠が一意または採点可能
- 語彙/文法 chronology 0違反
- fullTranslation / slashRows / evidenceJp 同期
- 山口県型100題の英作文・freeWrite count = 0
